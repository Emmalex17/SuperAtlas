# SuperAtlas UI parity kit

1. Copy `docs/` and `tools/` into the root of the repository (merge with existing folders) and commit them on `staging`.
2. Open `docs/PARITY_PROMPT.md` and paste everything below its line into Claude Code.

Contents: the approved prototype and its source, an 80-screen inventory with 144 reference screenshots, the prototype data for a mock data layer, the prototype's automated checks, and a parity-check script.

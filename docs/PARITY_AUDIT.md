## Deliberate, documented differences from the prototype

A small number of adaptations were made consistently across phases, each because the prototype's own mechanism (a global click-delegation router reading `data-act`/`data-arg` attributes, server-string chart HTML with inert `go`/`drill` attributes) has no equivalent in a real Next.js/React app, not because the feature was skipped:

- **Chart drill-down → "View as table" / real navigation.** The prototype's `kTile()`/`chBars()`/etc. support a click-to-open-a-drawer-of-organisations ("drill") interaction via `data-act="drill"`. No app screen implements that drawer; instead, charts that have it in the prototype get the shared `ChartCard`'s "View as table" toggle (swaps the drawing for the equivalent numbers), and where a chart's segments map to a real page (e.g. the regulator dashboard's category bars, KPI tiles, Watchlist rows), those were wired to real navigation instead. Established in P5, reused in every phase with a chart or KPI row since.
- **Per-case "notice"/"evidence" and similar rich objects** were added to TypeScript types only where a later phase's screen actually needed to read or write them (e.g. `EnforcementCase.notice` added in P9), rather than speculatively matching the prototype's full `S.*` shape up front.

## Real, previously-undiscovered issues found and fixed along the way

Several genuine bugs — not prototype-parity gaps, but real defects — were found while rebuilding adjacent screens and fixed in passing. The fullest list is in each phase's own section, but the standouts: a seed-data bug where all 1,029 answers had `status: "answered"` but no actual value (P6); enforcement-case evidence entries with no `id`, producing broken `/regulator/reviews/undefined` links (P9); the Tasks drawer showing raw internal ids ("kolanut") instead of organisation/firm names, and silently missing 4 of its 11 task groups across the regulator and firm workspaces (P10); and a handful of 11px-vs-12px minimum-text-size regressions in shared CSS (P10).

One correction to the brief's own premise, confirmed early and unchanged since: **the favicon/app icons are not missing.** `src/app/icon.tsx` and `apple-icon.tsx` already generate the branded mark (landed in the "Polish pass" commit `86feda6`).

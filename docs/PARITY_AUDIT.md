## The 10 biggest gaps

1. **The organisation-side "Compliance" tabbed surface doesn't exist (P9, 0/15 matches — worst phase).** `org/compliance`, `org/compliance/programme`, and `org/exposure` have no routes at all; only a standalone, untabbed `/organisation/actions` page exists. The prototype's `compStatus()`/`compChip()` and exposure-level (High/Medium/Low) calculations have no equivalent anywhere in `src/lib` — confirmed by repo-wide grep.
2. **Assessors can't see what organisations actually submitted (P6, 0/11 matches — tied worst phase).** `firm/assess` only has 2 of 5 tabs; the Requirements tab jumps straight from the requirement text to the outcome picker with no "organisation's answers" section, no divergence warnings, no "Ask" button. `org/assessment` (the org-side counterpart: information requests, interviews, outcome preview) doesn't exist anywhere.
3. **~~Organisations and firms have no self-service workspace (P3).~~ Fixed 2026-10-21.** `org/welcome`, `org/team`, `org/profile` (all 5 tabs), `firm/welcome`, `firm/team`, `firm/profile` (all 5 tabs), `firm/apply`, `organisations/category`, and `organisations/profile`/`firms/profile`'s Compliance/Performance tabs are all built and live-verified. P3 is now 32/32 Matches.
4. **~~The entire regulator Settings section is missing (P2).~~ Fixed 2026-10-21.** All 7 `settings/*` screens built, the shared `SettingsShell` left-nav, the "Settings" sidebar entry, and the previously-orphaned data layer (`schemes.json`, `deadlines.json`, `findingClasses.json`, `compliance.json`, `actionTypes.json`) is now live. P2 is 24/24 Matches.
5. **Firms have no way to verify organisation-submitted fixes (P7).** `firm/findings` and `firm/finding` don't exist anywhere — confirmed via repo-wide grep for "Fixes to verify"/"Being fixed"/"Verified and closed", zero hits. This breaks the findings-remediation loop (org submits fix → firm verifies → regulator closes).
6. **~~The app shell is a simplified rewrite, not a port (P10).~~ Substantially fixed 2026-10-21.** The sidebar now has section groupings (Supervise/Assess/Collect etc.) with live count badges, a Help dialog, and a "Powered by SuperAtlas" footer; the top bar has a working Ctrl/⌘K command palette (`src/lib/search.ts`), a tasks button with live counts (`src/lib/tasks.ts`), and the bell/user menu are real popovers; there's now a 15-minute idle-timeout warning dialog. Still missing: a Settings nav entry (no `settings/*` routes exist yet — P2), real per-page breadcrumbs (the `crumbs` prop exists on `AppShell` but no page passes it yet), and the sidebar's tenant-logo/"Supervised by X" brand block + collapse toggle (cosmetic, still shows the SuperAtlas logo instead).
7. **No programme-creation path and no programme analytics (P5).** `programmes/new`'s 6-step wizard doesn't exist — both "New programme" and "Continue setup" buttons are dead. `programmes/view`'s Analytics tab (cycle/category selectors, 7 stat cards, submission-by-category chart) is entirely absent from the tab list.
8. **No requirement/regulation authoring surface exists (P4).** `library/requirement`, `library/edit`, `library/ai` are all missing; the regulation page's "Actions" card (Edit/Add requirement/New version/Publish) is gone; all three action buttons on the library list ("Add regulation", "Import spreadsheet", "Add with AI") are dead.
9. **~~The invitation accept-flow is missing, and sign-in still links where it shouldn't (P1).~~ Fixed 2026-10-21.** All three invitation routes are built and live-verified pixel-identical to their reference screenshots, full flow working end to end; `signin`'s `/register` link is removed. P1 is now 16/16 Matches.
10. **Data returns: no Insights tab, no template builder (P8).** `returns`' tab bar has 3 of the prototype's 4 tabs (Insights is gone, content and all). `returns/template` (the return-template builder: Basics, Fields table, Publish) doesn't exist, and its launch buttons are either dead or mis-wired to open the wrong dialog.

~~Chart-kit/KPI primitives are also mostly unported~~ — built 2026-10-21: `chBars`, `chStack`, `chFunnel`, `chHeat`, `chDots` (`src/lib/charts.ts`), `KTile`, `ChartCard`/`MiniTable`, and a shared `StatusChip`/`statusTone()` and `FilterPills` (`src/components/ui.tsx`), all with matching CSS ported into `globals.css`. Not yet exercised by any real screen — no phase screen uses them yet, so treat as built-but-unverified-in-context until the first dashboard/analytics screen that needs one (P5's Analytics tab, P8/P9's Insights tabs, P10's dashboards) is built against it. Chart-kit drill/click interactivity (open a drawer of organisations on click) was deliberately left out for now — build it when the first caller needs it.

One correction to the brief's own premise: **the favicon/app icons are not missing.** `src/app/icon.tsx` and `apple-icon.tsx` already generate the branded mark (landed in the "Polish pass" commit `86feda6`). Treat that agreed-difference item as done.

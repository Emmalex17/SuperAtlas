# SuperAtlas

A regulatory compliance platform with three workspaces — regulator, supervised organisation, and assurance firm — each scoped to its own account at sign-in, with no cross-workspace switching.

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS. Backend (Supabase) wiring comes in a later phase; this build is frontend-only against mock/demo data.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
